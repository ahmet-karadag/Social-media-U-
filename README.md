# Social Media Application (iOS UI) 📱

This repository hosts the native iOS frontend of the full-stack social media application, built entirely using Apple's modern declarative UI framework, **SwiftUI**.

> **Status:** Work in Progress (WIP) — Front-end application is being developed progressively alongside the completed sections of the dedicated Node.js/TypeScript backend API.

## 🛠️ Tech Stack & Architecture
- **Framework:** SwiftUI
- **Language:** Swift
- **Design Pattern:** MVVM (Model-View-ViewModel) for clean separation of concerns and reactive state management.
- **Networking:** URLSession (Designed to fetch, send, and synchronize data with the custom backend API).
